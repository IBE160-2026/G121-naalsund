### Result
- **`ARCHITECTURE-SPINE.md`** (status final), 25 ADs. The main choices:
  - Modular monolith: FastAPI slices `identity` / `swings` / `coach` / `system`, plus a pure analysis engine `aicoach_engine` (pipes-and-filters, runnable from the CLI, FR-6).
  - Docker Compose with Caddy (one origin on `0.0.0.0:8080`, reachable from the phone over Wi-Fi), Next.js 16, FastAPI with an in-process worker, and Postgres 18.
  - Files on local disk behind a `FileStore` interface; Supabase comes in the next phase.
  - **Dropped from technology.md:** Redis, Supabase, Railway, payments, email, backups.
  - **Kept from technology.md:** the mock fallback, feature flags (now read at runtime from `/api/config`), bcrypt + JWT (now in an httpOnly cookie so video playback works), pydantic-ai → OpenRouter, the aiosqlite tests, and the no-`rollback()` rule.
  - The analysis job lives as a DB row: claimed with `SKIP LOCKED`, progress through an `on_step` callback, one terminal write, retry only from `failed`.
  - One result document, `AnalysisResult`, with evidence IDs `E<n>`, plus one list row, `LibraryRow`.
  - `rules.yaml` has one schema and one loader, with a `possible_only` status for the FR-9 fallback.
  - A grounding check with separate rules for explanation, observation and chat; chat returns 503 when the model is down, as the PRD and UX say.
  - Pose estimation is behind a port (MediaPipe 1.2.3 vs RTMPose, decided by the spike); the model files are built into the image.
  - Stack: Python **3.14** (3.13 has been security-only since 2026-10-01), uv 0.13, Node 26 LTS, TypeScript 5.x, shadcn 4.23.0 with an explicit base choice, and `opencv-contrib-python-headless` as the only cv2.
