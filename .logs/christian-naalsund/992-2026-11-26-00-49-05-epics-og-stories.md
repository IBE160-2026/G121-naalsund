# Epics og stories

## 2026-11-26 kl. 00:49 — Christian Naalsund

### Oppgave
Bryte PRD + UX (DESIGN.md/EXPERIENCE.md) + arkitektur (ARCHITECTURE-SPINE.md, setup-guide.md) ned i epics og stories med `bmad-create-epics-and-stories`. Brukerens føringer: epics som **vertikale skiver** (kode så isolert som mulig), men DRY via felles mapper/biblioteker; skrive strukturen inn i arkitekturen; bruke subagenter til å skrive stories.

### Plan
- Steg 1: krav-inventar fra PRD, addendum, spine, setup-guide og UX → FR-1–20, NFR-1–12, SM-1–13, AR-1–36, UX-DR1–50. Beslutninger: JPEG-still som nøkkelbildebakgrunn med SVG-overlegg, fonter selvhostet med `next/font`, ikke-kodearbeid (spike, testsett, sjekkpunkter) som stories, åpne UX-spørsmål bygges som deres antakelser.
- Steg 2: 8 epics i P1/P2/P3-rekkefølge, FR-dekningskart, ny seksjon «Code Organisation (vertical slices)» med felles mapper, slice-regler og hand-offs mellom epics.
- Steg 3: én subagent per epic (6 stk., Epic 7+8 samlet) skrev utkast i `planning-artifacts/.working/stories/`; flettet inn i `epics.md`. Fem beslutninger fra story-gjennomgangen godkjent («ok to all»).
- Steg 4: sluttvalidering (dekning, startmal, tabeller ved første behov, story-kvalitet, avhengigheter, filchurn).
